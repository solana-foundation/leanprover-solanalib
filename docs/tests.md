# Test and checker index

Generated by `python3.12 scripts/generate-test-index.py`; CI checks it with `--check`. Every Lean scenario, example, checker and test aggregator under the listed source roots is linked below. Aggregators and harness helpers are included for navigation; file counts are not coverage claims.

Run commands from the repository root after [setup](getting-started.md). `just check-all` runs all regular suites, including proof/source audits, replay controls and documentation. Fresh native reproduction uses the separate `test-native-runtime` and `test-native-library` recipes. The [gap index](model-gaps.md) records omissions and unproved connections.
