# Library and test index

Models are organized by library and function. The [source registry](source-map.json)
names each contract and its individual clients; [version compatibility](VERSION_COMPATIBILITY.md)
records reviewed releases and build conditions. Each row covers the listed subset
of its library.

The tests column links the mathematical `Test` root and the native conformance
families. Run a family with `run.py --model-only --family NAME`; the
[testing guide](../../tools/library-conformance/README.md) gives full commands
and per-driver native reproduction. Shared protocol tests live in
[SolanalibTest.Specs.Core](SolanalibTest/Specs/Core.lean), including
[array construction](SolanalibTest/Specs/Core/OwnedArray.lean).

The generated [complete test index](../../docs/tests.md#sdk-scenarios) links every scenario module under each crate root, every conformance checker, all Python control suites and all native drivers with their corpora. Use [the SDK extension walkthrough](../../docs/extending.md#sdk-walkthrough) to add a function with its witnesses, applicability and native evidence.
